# Salut, je suis Basile Malin 👋

## Développeur web PHP / Symfony & PHP / WordPress

Après plus de dix ans de terrain industriel — soudure, maintenance, électromécanique — je me suis reconvertis dans le développement web. Diplômé Concepteur-Développeur d'Applications (ENI, CCP1/CCP2), je construis des applications complètes, de la base de données au déploiement sur mes propres serveurs.

Mon quotidien couvre trois casquettes complémentaires : **développeur** (PHP/Symfony, WordPress), **administrateur systèmes** (Proxmox, Linux, réseaux) et **support technique** — trois métiers qui se renforcent : je code, je déploie, et je dépanne ce que j'ai déployé.

Ce que dix ans d'atelier m'ont appris et que le code réclame aussi : lire un besoin réel, travailler proprement, et réparer vite quand ça casse.

Actuellement basé entre Laval et Rennes (France), je recherche un poste de développeur web **PHP/Symfony** ou **PHP/WordPress** en Mayenne ou Ille-et-Vilaine.
